# @fe/icons

This package contains SVG icons used in the fe platform, sourced from [Streamline](https://streamlinehq.com).

## Attribution

Icons in this package are from Streamline (https://streamlinehq.com). Some icons are licensed under Creative Commons 4.0 Attribution (CC BY 4.0), while others are free to use under Streamline's free license.

See the [LICENSE](./LICENSE) file for detailed licensing information.

## Usage

This package is used internally by the fe platform and is not published to npm. The icons are processed and converted for use in the documentation site and platform UI.

## Source

Icons were extracted from the `@iconify-json/streamline` package using the script in `scripts/extract-svgs.ts`.
