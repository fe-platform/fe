## Build Pipeline (High-Level)

```
Source Publish
    ↓
Registry accepts TypeScript source + manifest
    ↓
Build Server triggered
    ↓
Resolve dependencies (other fe: imports, npm packages)
    ↓
Bundle with Bun (current browser targets)
    ↓
Extract static imports → generate modulepreload hints
    ↓
Rewrite dynamic imports → inject __fePreload calls
    ↓
Generate import map entries from exports field
    ↓
Store import metadata in manifest
    ↓
Deploy artifacts to CDN
    ↓
Update import map (atomic)
```

## MFE Manifest Schema

```typescript
interface MFEManifest {
  name: string                          // @org/mfe-name
  version: string                       // semver
  exports: Record<string, string>       // subpath → source file
  
  importMetadata?: {
    modulepreload?: string[]
    preload?: Array<{ href: string; as: string }>
    prefetch?: string[]
  }
  
  dependencies?: {
    fe?: string[]                       // fe:@org/other (no version — One Version Policy)
    npm?: Record<string, string>        // npm packages (platform resolves to single version)
  }
  
  style?: {                             // Optional, default: scoped
    scope?: "scoped" | "global"
  }
  
  permissions?: {                       // Optional, default: allow all
    state?: {
      read?: string[]                   // State slices readable
      write?: string[]                  // State slices writable (must own)
    }
    net?: string[]                      // fe:net/* subpaths accessible
    storage?: string[]                  // local:*, session:* keys
    fe?: string[]                       // Other MFE imports allowed
  }
  
  ai?: {                                // Optional, for agent discovery
    description?: string
    capabilities?: string[]
    intents?: string[]
    inputs?: Record<string, object>
    outputs?: Record<string, object>
  }
  
  fallback?: string                     // Optional, path to fallback component for failure isolation
}
```

## Runtime Components

### Import Map

Generated by platform. Injected into HTML. Maps all `fe:` specifiers to CDN URLs.

### Metadata Manifest

JSON object mapping `fe:` specifiers to their import metadata. Loaded at app init. Consumed by `__fePreload`.

### __fePreload Runtime

Injected by build. ~20 lines. Looks up specifier in metadata manifest, appends `<link>` tags, returns immediately.

### fe:state Store

Zustand store instance. Exposed via `fe:state`. MFEs use standard Zustand patterns.
